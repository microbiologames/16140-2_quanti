# Format du fichier d'entrée

> **À rédiger** une fois les exemples de fichiers déposés dans le dépôt privé de
> références (voir [`REFERENCES.md`](REFERENCES.md)).

Ce document décrira :

- la structure attendue (onglets, colonnes, unités) ;
- pour chaque champ : obligatoire ou non, type, valeurs admises ;
- les **tolérances du parseur** : ce que l'application accepte en écart au format nominal
  et comment elle le normalise ;
- les cas rejetés et le message correspondant.

Il servira à la fois de spécification de développement et de notice pour l'équipe.
